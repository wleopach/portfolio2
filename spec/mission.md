# Mission

**Project:** Leonardo Pacheco — Personal Portfolio Website

---

Build Leonardo Pacheco's definitive personal portfolio — a fast, modern, and highly functional website that showcases his identity, skills, projects, and experience in the most compelling way possible.

## Goals

- **Personal brand** — Create a memorable first impression for recruiters and collaborators. The site must feel professional, distinctive, and uniquely Leonardo's.

- **Beyond static content** — Embed an AI chatbot powered by GPT-4o that lets visitors have a real conversation about Leonardo's background, skills, and projects, instead of just scrolling through a page.

- **Memorable interactions** — The technologies section is a live 3D interactive sphere where real brand logos orbit in space, conveying depth and mastery at a glance.

- **Production quality** — Built on Next.js 14 so the site is fast by default, fully SSR, SEO-ready, and trivially deployable. Every push to `main` goes live on Vercel automatically.

## Success Criteria

| Criterion | Target |
|---|---|
| Lighthouse performance | ≥ 90 |
| Lighthouse SEO | 100 |
| First Contentful Paint | < 1.5s |
| Chatbot response time | < 3s |
| Mobile responsive | All breakpoints |
| Deploy on push | Zero manual steps |

## Out of Scope

- Blog or CMS
- Authentication
- Analytics dashboard
- Multi-language support
